Customer Churn Analysis

Project Overview
This project analyzes customer churn data to identify the key factors that lead customers to leave a company. The goal is to uncover patterns in customer behavior and provide actionable insights to improve customer retention.

Objectives

Analyze customer demographics and account information.
Identify factors influencing customer churn.
Compare churn rates across different customer segments.
Generate insights to support retention strategies.

Tools Used

Excel / Python
Pandas
NumPy
Matplotlib
Power BI (optional)

Key Analysis

Overall churn rate analysis.
Churn by gender, age group, and contract type.
Monthly charges and tenure analysis.
Customer segmentation based on churn behavior.
Data visualization and dashboard creation.

Key Insights

Customers with shorter tenure showed higher churn rates.
Month-to-month contract customers were more likely to churn.
Higher monthly charges were associated with increased churn.
Long-term contract customers had better retention rates.

Outcome
The analysis helped identify high-risk customer segments and provided recommendations to improve customer retention and reduce churn.
